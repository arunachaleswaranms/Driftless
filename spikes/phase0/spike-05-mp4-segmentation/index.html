Driftless Phase 0

Spike 0.5 — MP4 Parsing & Segmentation

Inspect a locally selected MP4 with MP4Box.js 2.4.1, reading it in bounded File.slice() blocks, and generate fragmented-MP4 initialization and media segments in memory. Segments are verified, summarised, and then released. Nothing is uploaded, stored, or played: connect-src and media-src are 'none', and there is no MSE, WebRTC, analytics, or telemetry on this page.

Source and experiment

The selected file is treated as untrusted input. A header-only box scan and a bounded moov check run before MP4Box.js sees any bytes.
