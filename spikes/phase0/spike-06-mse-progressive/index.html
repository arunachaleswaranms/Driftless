Driftless Phase 0

Spike 0.6 — MSE Progressive Playback

Plays a locally selected MP4 (H.264 + AAC) through Media Source Extensions. The file is read in bounded File.slice() windows and cut into keyframe-aligned fMP4 segments with the Spike 0.5 plan. A deterministic scheduler then releases the segments over time to simulate progressive arrival. Nothing is uploaded: connect-src is 'none', and media-src allows only the page's own MediaSource blob: URL. There is no WebRTC, storage, analytics, or telemetry on this page.
