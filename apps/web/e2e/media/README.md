# Browser test media

Small synthetic videos used by the Playwright local-player tests. They are read from disk by the tests only; they are not under `public/` or `src/` and are not part of the production build.

## Provenance

Both files were generated by [`scripts/generate-test-media.mjs`](../../scripts/generate-test-media.mjs). The script draws every frame from a fixed pattern: a solid background whose color changes each second, one white marker per elapsed second along the top, and a white bar that sweeps across the frame once per second. They contain no recorded, personal, or third-party material.

Frames are written as PPM, compressed to baseline JPEG by `cjpeg`, and piped as MJPEG to FFmpeg, which encodes VP8 into WebM with a keyframe every second, single-threaded, with bit-exact container flags and no metadata.

Generation command, run from `apps/web/`:

```sh
CJPEG=/opt/homebrew/opt/jpeg-turbo/bin/cjpeg \
FFMPEG=~/Library/Caches/ms-playwright/ffmpeg-1011/ffmpeg-mac \
npm run test-media
```

Tools used: libjpeg-turbo 3.2.0 `cjpeg` and Playwright's bundled FFmpeg `n7.0.1-playwright-build-1011`, on macOS 26.6.2. Two consecutive runs produced byte-identical files. Other tool versions may produce different bytes; the committed files and the digests below are authoritative.

## Why WebM and VP8

The generation toolchain available when these files were made, Playwright's bundled FFmpeg, encodes only VP8 into WebM. VP8 in WebM plays in the Playwright Chromium build the tests use and exercises the same player code as any other format. These files say nothing about the MP4/H.264/AAC Progressive Watch target or about any browser's support for it.

The files have no audio track, so they do not exercise audio output or any audio-specific autoplay restriction.
